# Trattoria SOLE（トラットリア ソーレ）公式Webサイト

代々木上原で15年間営業を続けるイタリアンレストラン「Trattoria SOLE（トラットリア ソーレ）」の公式Webサイトです。

## ブランドコンセプト
**「大切な日には、心に残る一皿を。」**

誕生日・結婚記念日・プロポーズ・大切な人との食事など、かけがえのないひとときを旬のイタリア料理と厳選ワインで彩るレストランの世界観を、「温かな品格」と「一番の見やすさ・迷わない予約導線」で表現しています。

## ページ構成（全4ページ）
- `index.html`：**TOP**（ファーストビュー、記念日のおもてなし、看板料理、コース案内、ワイン、アクセス、コンセプト・シェフの想い）
- `menu.html`：**MENU**（アラカルト全16品のお品書き、記念日特別コースほか全3コース詳細）
- `wine.html`：**WINE**（グラス・ペアリング案内、赤・白・スパークリング厳選9銘柄リスト、ノンアルコール案内）
- `reservation.html`：**RESERVATION**（24時間受付オンライン仮予約リクエストフォーム・確認画面・キャンセルポリシー）

## 技術仕様
- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク不要・高速表示）
- PC・タブレット・スマートフォン完全対応（レスポンシブデザイン）
- Google Fonts（`Cormorant Garamond` / `Shippori Mincho`）
- Vercel デプロイ対応（`vercel.json` 設定済み）
